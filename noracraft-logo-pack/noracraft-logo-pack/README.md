# NORAcraft logo pack

Original NORAcraft app branding: geometric N with integrated play symbol.

Brand colors:
- Primary: #8B5CF6
- Accent: #C084FC
- Deep purple: #4C1D95
- Dark background: #0B0B12

## Android use

Copy the files under `android/res/` into the app module's `src/main/res/` directory. `ic_launcher.xml` is an adaptive launcher icon using the foreground and background vectors; the foreground is also suitable for monochrome launcher fallback. The PNGs are useful for splash screens, marketing, and Compose/ImageView placement.

The PNG logo concepts were generated as original NORAcraft artwork. The Android vector launcher geometry is included for scalable, source-controlled rendering.
